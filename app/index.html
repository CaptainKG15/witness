Witness

An on-chain evidence notary. GenLayer validators read a web page, agree on what it says, and store that agreed reading so anyone can check later whether the page changed.

    What Witness records: the validators' agreed reading of a page (does it support the claim, what kind of page it is, whether it tried to inject instructions). It does not store raw page content. Pages that change between validators' fetches can cause disagreement or a "changed" result without a real change.

    On Studio this app uses a throwaway in-browser account that holds no funds. On Bradbury it uses your browser wallet and you approve each transaction.
